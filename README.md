# English for Newcomers

## Project overview

English for Newcomers is a GEAP 103 partner project for adult Spanish-,
Persian-, and French-speaking immigrants who have recently moved to Toronto
and the Greater Toronto Area (GTA). It is designed for beginner English
learners at the A1-A2 level.

The interface supports English, Spanish, Persian, and French, including
right-to-left layout for Persian.

## Learning focus

The app focuses on practical English vocabulary and grammar for everyday life
in Canada. It also includes speaking practice for Spanish-speaking learners,
with beginner English phrases, Spanish translations, browser-based listening
and speech recognition, and simple phrase matching. Speech recognition can
vary and is not a pronunciation score; some browsers may require an internet
connection.

## Technology

The starter app uses HTML, CSS, and JavaScript. It does not need a framework or
external dependencies.
